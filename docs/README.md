# date.devchopra.life — Project Knowledge Base

A complete product, content, design, and implementation brief for building **date.devchopra.life** with Antigravity.

## Product in one sentence
A playful, romantic, meme-heavy, mobile-first interactive introduction to Dev Chopra — designed to make a visitor smile, get curious, and start a real conversation.

## The central rule
**The website introduces Dev. The conversation discovers Dev.**

Do not turn this into a full autobiography, résumé, dating app, or application portal. Reveal enough to create curiosity; leave stories, memories, and personal details for an actual conversation.

## Recommended way to use this

1. Create a fresh GitHub repository, for example `date-devchopra`.
2. Open the repository folder in Antigravity.
3. Add this entire knowledge base to the repository under `/docs`.
4. Read `01_PRODUCT_BRIEF.md` and `10_ANTIGRAVITY_MASTER_PROMPT.md`.
5. Give Antigravity the master prompt. Ask it to inspect all `/docs` files before coding.
6. Build the first version using local placeholder media. Do not wait for all photos and videos.
7. Review the mobile experience first, then desktop.
8. Add your selected media and replace placeholders.
9. Deploy to Vercel and connect `date.devchopra.life`.
10. Only add Supabase if a real feature requires persistent data.

## Important facts to verify before launch

- Height was provided as “5.7 feet”. Confirm whether this means **5 ft 7 in** before publishing. It is not needed on the public landing page.
- Confirm whether you want to display your exact date of birth or simply your age. Prefer displaying age dynamically or omitting it.
- Confirm which photos/videos you are comfortable making public.
- Review every statement and joke before launch. The site should feel confident and playful, not boastful or misleading.
